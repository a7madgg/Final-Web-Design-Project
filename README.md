# Final-Web-Design-Project
YU Store is a modern and responsive university store website developed for the CIS 201 – Fundamentals Web Design course at Al Yamamah University.

The project was built using only:

HTML5
CSS3
JavaScript

The website focuses on:

Responsive design
Clean UI/UX
Interactive JavaScript features
Modern layout structure
